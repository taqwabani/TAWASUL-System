# TAWASUL-System
TAWASUL: An Electronic School Communication System Between Schools and Parents 

## Project Description
TAWASUL is a web-based communication system developed to improve communication between parents and school administration.

The system allows parents to send inquiries, follow responses, and view school announcements, while administrators can manage announcements and reply to parent inquiries through a simple and organized interface.

The project was developed using a layered architecture approach to improve system organization, maintainability, and future scalability.

## Current Features
- User Authentication System
- Role-Based Access Control (Admin / Parent)
- Parent Inquiry Management
- Admin Reply System
- School Announcement Management
- Session Management
